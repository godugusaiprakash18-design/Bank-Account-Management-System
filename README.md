# Bank-Account-Management-System

# INTRODUCTION:
The application allows a user to create an account, deposit money, withdraw money, check the account balance, and exit the system.


# OBJECTIVES :
1.To understand the basics of Python programming.
2.To create a simple menu-driven application.
3.To perform deposit and withdrawal operations.
4.To maintain and display the current account balance.
5.To apply conditional statements and loops in a practical application.

# Features of the Application
*Create Account – Stores the account holder's name and account number.
*Deposit Money – Adds a valid positive amount to the account balance.
*Withdraw Money – Withdraws money only when sufficient balance is available.
*Check Balance – Displays account details and the current balance.
*Exit – Ends the banking application.


REQUIREMENTS:
- Python 3.x


## How to Run
```bash
python "application.py"
```

# CONCLUSION

The Simple Banking Application successfully demonstrates how Python can be used to build a basic real-world application.
